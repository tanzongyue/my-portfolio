## 七项目图片核验

“WebP 文件”包括封面以及部分作品的高分辨率原图，因此多于详情中的展示图数量。

| 项目 | 展示图 | WebP 文件 | 原始文件总字节 |
| --- | ---: | ---: | ---: |
| ReadPaper 沉浸式阅读体验 | 23 | 26 | 3,582,286 |
| ReadPaper 移动端与 iPad | 8 | 11 | 2,401,842 |
| ReadPaper 运营与品牌 | 12 | 14 | 2,155,260 |
| 低空视界大屏展示 | 5 | 6 | 708,754 |
| RWA 交易平台 | 3 | 4 | 656,514 |
| RWA B端平台 | 5 | 6 | 588,444 |
| 其他作品 | 6 | 7 | 498,638 |
| 总计 | 62 | 74 | 10,591,738 |

设备预览合计 268,088 字节，对应原图合计 1,545,050 字节，减少约 83%。这里只用于三维屏幕；作品详情仍保留原有清晰度。

字体样式和地址完全自托管。字体授权文件在 `licenses/dm-sans-OFL.txt`、`licenses/manrope-OFL.txt`，Three.js 授权在 `licenses/three-MIT.txt`。

源码内的项目 `src`、`fullSrc`、`cover` 已逐项核对本地文件。构建核验脚本同时验证所有原图、设备图、字体、PDF 的哈希一致性、代码分包、CSS/HTML 外部依赖和 EdgeOne 回退配置：

```sh
npm run build
npm run verify:production
```

网站运行时无需 Google、Kimi、jsDelivr、unpkg 等海外资源服务。许可证、部署文档和构建工具中的官方网址不属于浏览器运行依赖。
